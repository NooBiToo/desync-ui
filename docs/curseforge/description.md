**Сначала поставьте ElvUI** — с [tukui.org](https://tukui.org) или через приложение Wago/WowUp. На CurseForge ElvUI нет, поэтому CurseForge не может поставить его сам. WindTools и mMediaTag CurseForge поставит вместе со сборкой.

# DeSync UI

Сборка интерфейса для **WoW Forever** на ElvUI: аккуратный вид ElvUI вместе с настройками **WindTools** и **mMediaTag** и набор полезных модулей.

## Что внутри

- **Вид ElvUI.** Профиль «DeSync UI»: расположение панелей, рамки, индикаторы здоровья, шрифты PT Sans Narrow и Expressway, настройки WindTools и mMediaTag.
- **Банк в сумке.** Кнопка в сумке ElvUI показывает, что лежит в банке, где бы вы ни были. Банк запоминается при каждом визите к банкиру, видны банки всех ваших персонажей.
- **Кто кого бьёт.** В группе и рейде на индикаторах здоровья врагов: меч с числом — сколько участников держат врага в цели, щит — цель танка.
- **Прогресс квеста в подсказке.** Исправляет пропадающие строки Questie в подсказке моба.
- **Кто что выбрал в розыгрыше.** Счётчики и имена на кнопках «Нужно / Не откажусь / Пас» панели розыгрыша ElvUI.
- **Жезл не мешает заклинаниям** (по желанию). Клавиши заклинаний сначала сбивают выстрел жезлом, потом произносят заклинание. Для мага, жреца и чернокнижника.
- **Кнопки у миникарты** (по желанию). Убирает значки аддонов с миникарты в список «Модификации».

## Установка

1. Поставьте ElvUI (см. выше), затем DeSync UI через CurseForge.
2. Войдите в игру: откроется окно установки DeSync UI. Нажмите «Установить» → «Применить» → «Перезагрузить интерфейс».
3. Модули включаются и настраиваются в `/ec → DeSync UI`. Окно установки можно открыть снова командой `/desync install`.

Установка создаёт отдельный профиль ElvUI «DeSync UI» и не трогает другие ваши профили. Личные настройки ElvUI персонажа (включённые модули ElvUI, обложки) заменяются настройками сборки. Второй персонаж просто подключает уже созданный профиль, не затирая ваши правки.

## Требования

- WoW Forever
- ElvUI (tukui.org / Wago / WowUp)
- ElvUI WindTools, ElvUI mMediaTag & Tools (ставятся автоматически)
- Questie — по желанию

**English.** DeSync UI is an ElvUI-based interface pack for WoW Forever: a ready ElvUI profile with WindTools and mMediaTag settings, plus modules — a bank viewer in the ElvUI bag, group target counters and tank-target marks on nameplates, a fix for Questie quest progress vanishing from tooltips, loot roll counters, and optional wand/spell and minimap-button helpers. Install ElvUI first (tukui.org or Wago, it is not on CurseForge), then log in and follow the install window (`/desync install` to reopen). Texts in the pack are in Russian.
