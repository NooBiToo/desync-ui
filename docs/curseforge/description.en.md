# DeSync UI

An interface pack for **WoW Forever** built on ElvUI: a clean ElvUI look together with **WindTools** and **mMediaTag** settings, plus a set of handy modules.

## What's inside

- **ElvUI look.** The "DeSync UI" profile: bar and frame layout, unit frames, nameplates, PT Sans Narrow and Expressway fonts, WindTools and mMediaTag settings.
- **Bank in your bag.** A button in the ElvUI bag shows what is in your bank, wherever you are. The bank is remembered on every visit to a banker, and you can browse the banks of all your characters.
- **Who's hitting what.** In a party or raid, enemy nameplates show a sword with a number (how many group members are targeting that enemy) and a shield on the tank's target. Works in the open world: inside Forever dungeons the game hides everyone's target from addons.
- **Quest progress in tooltips.** Fixes Questie's quest lines disappearing from mob tooltips.
- **Who rolled what.** Counters and names on the Need / Greed / Pass buttons of the ElvUI loot roll frame.
- **Wand doesn't block spells** (optional). Spell keys first stop your wand shot, then cast the spell. For mages, priests and warlocks.
- **Minimap buttons** (optional). Moves addon icons off the minimap into the Addon Compartment list.

## Installation

1. Install ElvUI (see above), then install DeSync UI through CurseForge.
2. Log in: the DeSync UI install window opens (after ElvUI's own setup window, if ElvUI shows one). Click **Install** → **Apply** → **Reload UI**.
3. Modules are turned on and configured in `/ec → DeSync UI`. You can reopen the install window any time with `/desync install`.

Installing creates a separate ElvUI profile "DeSync UI" and leaves your other profiles alone. The character's private ElvUI settings (enabled ElvUI modules, skins) are updated with the pack's settings, and the UI scale is set for the whole account. A second character simply switches to the existing profile without wiping your tweaks; when a new version of the look comes out, you are offered an update once.

## Requirements

- WoW Forever
- ElvUI (tukui.org / Wago / WowUp)
- ElvUI WindTools, ElvUI mMediaTag & Tools (installed automatically)
- Questie — optional

The pack's in-game texts are in Russian.
