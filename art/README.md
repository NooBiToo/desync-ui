# DeSync UI logo
Original geometric D with a horizontal signal split and an offset darker-blue layer on a dark rounded-square tile.
Palette direction: accent cyan #33CCFF, darker blue #087CAD, near-black #101418; model-rendered shades vary slightly.
Created with OpenAI built-in image generation; resized and exported using Pillow 13.0.0 (RGBA PNG and uncompressed 32-bit TGA).
Original work created for DeSync UI; no Blizzard, WoW, ElvUI, Tukui or CurseForge artwork, fonts or logos were used.
